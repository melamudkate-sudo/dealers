# DEMIAND — GitHub Pages Ready

Эта папка содержит готовый статический сайт: `index.html`, `assets/` и скрытый
файл `.nojekyll`. Сборка и установка npm для публикации не нужны.

1. Загрузите **содержимое** папки в корень своего GitHub-репозитория, сохранив
   структуру `assets/`. Не загружайте только один `index.html`.
2. В Settings → Pages выберите Deploy from a branch → main → / (root).
3. Дождитесь завершения публикации. Относительные пути подходят и для адреса
   вида `https://username.github.io/repository/`.

Шрифты Google загружаются из интернета. Просмотрщик 3D и декодер находятся в
`assets/vendor/`: для модели не нужен внешний CDN.
Форма открывает почтовый черновик; серверная отправка не предусмотрена.

Актуальная публикация: https://github.com/melamudkate-sudo/dealers — ветка `main`.
Сайт: https://melamudkate-sudo.github.io/dealers/

Локальные исходники редактируются в рабочей папке `demositedemi`; команда
`npm run build` собирает готовые файлы для публикации в `dealers/main`.
На рабочем компьютере путь этой папки записан в локальном `.pages-export-path`:
каждая успешная сборка обновляет и `dist/`, и эту папку. На другом компьютере
путь можно задать переменной `DEMIAND_EXPORT_DIR` перед `npm run build`.
Не редактируйте `dist/` вручную.

## Подключение домена

Эти же файлы можно загрузить в корень обычного статического хостинга. Пути к
ресурсам относительные — сайт не привязан к `/dealers/`. Для домена на GitHub
Pages задайте свой адрес в Settings → Pages → Custom domain и настройте DNS
у регистратора. Конкретный домен и DNS не менялись: адрес ещё не указан.

## Замена фото и видео

### 3D на первом экране

Сайт использует `assets/models/demiand-dk5100-fast.glb` (4,71 МБ вместо 32,79 МБ).
Отдельное упрощение геометрии не применялось: использованы Draco и текстуры WebP высокого
качества, максимум 2048 px. Это оптимизация для экрана, не побитовое сжатие без потерь.
Исходная модель сохранена рядом как `demiand-dk5100.glb` и автоматически не загружается.
При замене обновите `src` модели и ссылку `rel="preload" as="fetch"` в `<head>`.
Во время загрузки модель скрывает лёгкая SVG/CSS-анимация: тонкие металлические
орбиты движутся с постоянной скоростью, затем плавно растворяются за готовой 3D-моделью. Переход
запускается только после события загрузки модели, а не по условному проценту.
`assets/js/hero-intro.js` управляет этим переходом; анимация приостанавливается
вне первого экрана и в скрытой вкладке. В режиме уменьшения движения она отключена.
`assets/images/hero-model-poster.webp` — запасное превью именно этой модели:
оно используется без анимации, при ошибке или ожидании более 25 секунд.
Обновляйте его вместе с моделью. Позднее успешно загруженная 3D заменит превью.
GLB и превью запрашиваются с высоким приоритетом сразу при загрузке страницы.
Фактическое время появления интерактивной 3D зависит от сети и устройства;
при невозможности запустить WebGL остаётся статичное превью.

### Фото и ролики

Все медиа-рамки уже готовы: фотографии вписываются без обрезки, вертикальные
ролики имеют формат 9:16, окно фильма — 16:9. Технические надписи поверх
заглушек убраны. Четыре пары лайков/просмотров сохраняются поверх роликов.

Фотографии моделей и цветов находятся в `assets/images/catalog/`.
В `assets/js/script.js` модель перечисляет доступные цвета и точные имена файлов:
`['DK-2500', { white:'2500-5300wh.webp', black:'2500-5300bl.webp' }]`.
Переключатель цвета меняет именно фотографию, не накладывает цветной фильтр.
При открытии каталога у каждой модели выбран чёрный цвет.
Чтобы заменить фото, сохраните новый файл под тем же именем и в том же формате;
если имя или формат меняются, поправьте запись модели в `script.js`.
Предмет вписывается целиком (`object-fit: contain`) с небольшим полем вокруг.

- `2200-2400…` — общие фотографии DK-2200 и DK-2400 по соответствующим цветам.
- `2500-5300…` — общие фотографии DK-2500 и DK-5300.
- KF-3100 — один цвет, чёрный; KF-3200 — два, белый и чёрный.
- DK-2100 — белый и чёрный; DB-E1300 — белый, чёрный, серебристый и бордовый.

Фото оптимизированы без уменьшения детализации предметов: WebP lossless использован
только при уменьшении веса и совпадении декодированных пикселей. Остальные JPEG/PNG
сохранены без потерь. У DK-5000 и DK-5100 убраны избыточные поля фона с защитным
отступом, чтобы модели выглядели крупнее; корпус не обрезан.
Скрипт `scripts/prepare-catalog-images.cjs` в
исходниках позволяет повторить подготовку с библиотекой Sharp; оригиналы не меняются.
Три отдельные иллюстрации `catalog-airfryer-2700.png`, `catalog-coffee-3500.png` и
`catalog-blender-1200.png` используются только для выбора категорий.

Горизонтальный фильм уже подключён: `assets/videos/production.mp4`.
Его обложка — первый кадр, `assets/images/production-poster.jpg`; она
пропорционально заполняет рамку без чёрных полос. Положение кадра настраивается
в `.production-poster` через `object-position` (в `assets/css/design.css`).
Четыре рилса уже подключены по порядку: `assets/videos/marketing-01.mp4` …
`marketing-04.mp4`. Их первые кадры — `assets/images/marketing-01-poster.jpg` …
`marketing-04-poster.jpg`. При замене видео обновите и соответствующий постер.
Пути заданы в `data-video-src` и `data-video-poster` у `article[data-marketing-slide]`.
Старых фотографий-заглушек поверх роликов больше нет.

Превью рилсов, фильм производства и все 26 фотографий каталога начинают загружаться
сразу при открытии сайта; фото имеют низкий сетевой приоритет. Рилсы буферизуются
заранее при приближении к карусели. Активный ролик запускается без звука при появлении
в области просмотра и с начала при смене слайда; скрытые ролики стоят на паузе.
Кнопка справа внизу управляет стартом/паузой. На медленной сети или в режиме
энергосбережения браузер может отложить загрузку/автозапуск — остаются постер и кнопка.

- Фото находятся в `assets/images/`. Для простой замены сохраняйте имя файла,
  формат и пропорции. Если меняется имя — обновите соответствующий `src` в HTML
  или данные каталога в `assets/js/script.js`. Изображения каталога сейчас могут
  использоваться несколькими моделями: для отдельных фото задайте отдельные пути.
- Четыре ролика маркетинга: замените соответствующий `marketing-01.mp4` …
  `marketing-04.mp4` и постер под тем же именем. Формат — 9:16; лайки и просмотры
  сохраняются отдельно в HTML на контрастных плашках.
- Фильм производства уже подключён. Замените `assets/videos/production.mp4` и
  его обложку `assets/images/production-poster.jpg`. Рекомендуемый формат — 16:9,
  MP4/H.264. Текущий файл около 66,5 МиБ: для загрузки используйте Git/GitHub Desktop
  (веб-интерфейс GitHub не принимает файлы больше 25 МБ).
- Проверяйте точный регистр имён файлов: на хостинге `Video.mp4` и `video.mp4`
  могут быть разными файлами. После правок исходников выполните `npm run build`.

Форма использует `info@demiand.com` и открывает почтовый черновик. Для отправки
заявок без почтового приложения нужен отдельно подключённый сервис отправки;
такой сервис не входит в статический сайт.

# DEMIAND — GitHub Pages Ready

Эта папка содержит готовый статический сайт: `index.html`, `assets/` и скрытый
файл `.nojekyll`. Сборка и установка npm для публикации не нужны.

1. Загрузите **содержимое** папки в корень своего GitHub-репозитория, сохранив
   структуру `assets/`. Не загружайте только один `index.html`.
2. В Settings → Pages выберите Deploy from a branch → main → / (root).
3. Дождитесь завершения публикации. Относительные пути подходят и для адреса
   вида `https://username.github.io/repository/`.

Для шрифтов Google и интерактивной 3D-модели нужен интернет, как на локальном сайте.
Форма открывает почтовый черновик; серверная отправка не предусмотрена.

Актуальная публикация: https://github.com/melamudkate-sudo/dealers — ветка `main`.
Сайт: https://melamudkate-sudo.github.io/dealers/

Локальные исходники редактируются в рабочей папке `demositedemi`; команда
`npm run build` собирает готовые файлы для публикации в `dealers/main`.
На рабочем компьютере путь этой папки записан в локальном `.pages-export-path`:
каждая успешная сборка обновляет и `dist/`, и эту папку. На другом компьютере
путь можно задать переменной `DEMIAND_EXPORT_DIR` перед `npm run build`.
Не редактируйте `dist/` вручную.

## Подключение домена

Эти же файлы можно загрузить в корень обычного статического хостинга. Пути к
ресурсам относительные — сайт не привязан к `/dealers/`. Для домена на GitHub
Pages задайте свой адрес в Settings → Pages → Custom domain и настройте DNS
у регистратора. Конкретный домен и DNS не менялись: адрес ещё не указан.

## Замена фото и видео

- Фото находятся в `assets/images/`. Для простой замены сохраняйте имя файла,
  формат и пропорции. Если меняется имя — обновите соответствующий `src` в HTML
  или данные каталога в `assets/js/script.js`. Изображения каталога сейчас могут
  использоваться несколькими моделями: для отдельных фото задайте отдельные пути.
- Четыре ролика маркетинга: создайте `assets/videos/`, положите туда MP4 и
  добавьте `data-video-src="assets/videos/название.mp4"` к нужному элементу
  `article[data-marketing-slide]` в `index.html`. Формат — 9:16; показанные лайки
  и просмотры остаются у соответствующего слайда.
- Фильм производства: добавьте `data-video-src="assets/videos/production.mp4"`
  кнопке `.production-video` в `index.html`. Окно автоматически переключится
  с заглушки на плеер. Рекомендуемый формат — 16:9, MP4/H.264.
- Проверяйте точный регистр имён файлов: на хостинге `Video.mp4` и `video.mp4`
  могут быть разными файлами. После правок исходников выполните `npm run build`.

Форма использует `info@demiand.com` и открывает почтовый черновик. Для отправки
заявок без почтового приложения нужен отдельно подключённый сервис отправки;
такой сервис не входит в статический сайт.

# Видео DEMIAND

Горизонтальный `production.mp4` уже установлен; обложка взята из первого кадра.
Четыре вертикальных MP4 уже установлены в порядке файлов reel1–reel4 (H.264, AAC):

- `marketing-01.mp4` — вертикальное 9:16, 17.4M просмотров / 17.2K лайков.
- `marketing-02.mp4` — вертикальное 9:16, 17M просмотров / 243K лайков.
- `marketing-03.mp4` — вертикальное 9:16, 15M просмотров / 283K лайков.
- `marketing-04.mp4` — вертикальное 9:16, 16.7M просмотров / 197K лайков.
- `production.mp4` — горизонтальный фильм 16:9.

В `index.html` пути уже заданы через `data-video-src`; первые кадры задаются
через `data-video-poster`. Для замены сохраните имена файлов или обновите эти
атрибуты и ссылки предварительной загрузки постеров в `<head>`.
Превью находятся в `assets/images/marketing-01-poster.jpg` … `marketing-04-poster.jpg`.

Рекомендуемые размеры: 1080×1920 и 1920×1080. Сжимайте ролики для быстрой
загрузки: желательно менее 20 MB на ролик. Крупные файлы лучше разместить
на видеохостинге/CDN с прямым HTTPS-адресом MP4.
Рилсы автоматически играют без звука только в видимом активном слайде.
Перелистывание запускает выбранный ролик сначала; кнопка — пауза/старт.
Постеры грузятся вместе со страницей, MP4 рилсов — заранее перед каруселью.
Фильм производства загружается сразу, но воспроизводится только по нажатию.

Сохранены 720×1280, 30 fps и исходный звук. Ролики 1, 2 и 4 сжаты H.264 CRF 18
с fast-start; SSIM по всем кадрам 0,993–0,994 (не математически без потерь).
Ролик 3 уже был компактным и перенесён без перекодирования. Оригиналы не изменены.

Полная инструкция по фото, сборке и публикации — в README готовой папки.
